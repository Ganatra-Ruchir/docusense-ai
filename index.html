Honest by design

If retrieval confidence is low, the system says so instead of guessing. Extractive answers can't hallucinate facts not present in your documents.

⚡

Measured, not assumed

Every answer reports real latency and a real confidence score from the model — not a canned percentage.

🔐

Access-aware retrieval

Restricted documents are filtered out of the candidate set before search runs, not after — the model never even sees them.

Why this exists

Built against a real hiring checklist

This project follows a specific evaluation rubric: real architecture, real evaluation with baselines, honest error handling, and a working deployed demo — rather than a cosmetic chatbot UI.

📦

Models used

Xenova/all-MiniLM-L6-v2 for embeddings and Xenova/distilbert-base-cased-distilled-squad for extractive QA, both quantized ONNX builds served via Transformers.js.

🧪

What's measured

Retrieval Recall@1/@3, mean reciprocal rank, QA confidence score, and end-to-end latency — shown live in the Evaluation tab above, not claimed in prose.

🚀

Zero-ops deployment

Static HTML/CSS/JS. No database, no server, no secrets to rotate. Deployed to GitHub Pages and Vercel directly from this repository.

⚠️ This is a portfolio engineering demonstration, not a production compliance product. Document processing, embeddings and inference all happen locally in your browser tab via WebAssembly — no file you open here is uploaded anywhere.
